# Geak
## Global Education Access Kit

### Your one-click university application solution.

Geak build software innovations to help students discover university courses and gain access to opportunities they qualify for using sophisticated modern algorithms.

## 🚀 What we're building

Students shouldn't have to navigate dozens of university
websites to figure out what they can study.

Geak Assistant turns academic results into personalized
course recommendations.

## Products

### Geak Assistant
The student-facing application discovery platform.

### Geak Data API
The data infrastructure powering course eligibility,
institution and program information.


## 🎯 Mission

Make higher education discovery dramatically simpler
for students.

## 🌍 Vision

Start in South Africa.
Scale globally.
